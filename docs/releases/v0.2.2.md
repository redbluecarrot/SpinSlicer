# SpinSlicer v0.2.2

This maintenance release improves physical projection alignment, native builds, and the desktop controls.

### What's New in v0.2.2

- Fixed X/Y voxel ordering between mesh slices and the physical ray model.
- Built and verified the native SIRT projection backend for Windows and Linux release packages.
- Reduced peak memory while assembling the physical projection matrix in CSR chunks.
- Refined camera controls, viewport sizing, and projector playback layout.
- Added regression coverage for projection orientation, camera input, and release packaging.

Release packages are built and checked by GitHub Actions.
