# SpinSlicer v0.5.3 — Fix for the engine crash on Windows / Исправление падения движка на Windows

---

## English

### Fixes

- **Generating frames no longer fails on Windows** with `'utf-8' codec can't decode byte
  0xcf`. The engine process now sends ASCII-only messages to the window, so the
  console code page of a localized Windows (cp1251 and others) cannot break them, and
  stray output from native libraries is ignored instead of stopping the run.
- Includes everything from v0.5.2 (Settings page, step order, virtual print and
  taskbar icon fixes, 1024×768 projector resolution).

---

## Русский

### Исправления

- **Расчёт кадров больше не падает на Windows** с ошибкой `'utf-8' codec can't decode
  byte 0xcf`. Процесс движка теперь передаёт окну только ASCII-сообщения, поэтому
  кодовая страница консоли русской Windows (cp1251 и другие) их не ломает, а
  посторонний вывод нативных библиотек игнорируется и не останавливает расчёт.
- Включает всё из v0.5.2 (страница настроек, порядок шагов, виртуальная печать и
  иконка на панели задач, разрешение проектора 1024×768).
