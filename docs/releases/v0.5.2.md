# SpinSlicer v0.5.2 — Settings page, clearer step order, Windows fixes / Страница настроек, понятный порядок шагов, исправления для Windows

---

## English

### Changes

- **Settings page.** The printer page is now called Settings and is grouped into Vial,
  Projector, Optics and Resin. The projector group has the resolution, the projector
  refresh rate (Hz), picture offsets, gamma, contrast and irradiance; refractive indices
  are in their own fold-out.
- **Refresh rate check.** The rotation speed row warns when frames would change faster
  than the projector refresh rate you set.
- **Logical order of the side panel.** Model: orientation, scale, position, fit, exact
  position, voids. Light: quality, frames, results, then virtual print. Print: output,
  projector setup tools, speed, brightness, dose and plan.
- **Projector resolutions:** 1024×768 added, 4K removed. The saved resolution choice is
  reset once.
- **Print screen:** the extra frame-rate readout above the projector preview is gone.

### Fixes (Windows)

- **Virtual print** no longer keeps asking to recalculate the light right after a run:
  the preview is dropped only when the part has really moved.
- **Taskbar icon** is back: the app has its own Windows identity and uses the `.ico`
  for the window icon.

## Русский

### Изменения

- **Страница настроек.** Страница принтера теперь называется «Настройки» и разбита на
  «Колба», «Проектор», «Оптика» и «Смола». В «Проекторе» — разрешение, частота
  проектора (Гц), сдвиги картинки, гамма, контраст и облучённость; показатели
  преломления — в отдельном раскрывающемся блоке.
- **Проверка частоты.** Строка скорости вращения предупреждает, если кадры будут
  меняться чаще, чем частота проектора, которую вы задали.
- **Логичный порядок боковой панели.** Модель: ориентация, масштаб, положение,
  «влезает», точная позиция, отверстия. Свет: качество, кадры, результаты, затем
  виртуальная печать. Печать: вывод, настройка проектора, скорость, яркость, доза и план.
- **Разрешения проектора:** добавлено 1024×768, убрано 4K. Сохранённый выбор
  разрешения один раз сбросится.
- **Экран печати:** убрана лишняя надпись с частотой кадров над превью проектора.

### Исправления (Windows)

- **Виртуальная печать** больше не просит пересчитать свет сразу после расчёта:
  предпросмотр сбрасывается, только если деталь действительно сдвинули.
- **Иконка на панели задач** вернулась: у приложения свой идентификатор Windows, а
  для окна используется `.ico`.
