# SpinSlicer v0.2.3

This release brings frequently used print controls onto the main workspace and makes model scaling easier to control.

### What's New in v0.2.3

- Added a quick settings sidebar for vat mode and diameter, exposure, projection quality, frame resolution, and frame count.
- Kept optical calibration and projection engine tuning in the dedicated Settings tab.
- Added a uniform scaling checkbox to switch between proportional and per-axis model resizing, including the 3D scale handles.
- Expanded UI regression tests for the sidebar and scaling behavior.

Release packages are built and checked by GitHub Actions.
