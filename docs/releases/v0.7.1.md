# SpinSlicer v0.7.1 — Print files for SpinPrinter / Файлы печати для SpinPrinter

---

## English

### `.spin`: one file per print

- **Export for the printer.** Print → "Export .spin" saves the projection video together
  with everything the printer needs: the number of revolutions, the exposure tolerance,
  the print time, the rotation direction and the angle of the first frame, a 320×320
  preview of the part and the slice settings. A `.spin` file is a plain ZIP (stored, not
  compressed), so any archive tool opens it; a sha256 of the video catches a damaged copy.
- **Send to the printer.** Print → "Send to printer" uploads the `.spin` to a SpinPrinter
  over Wi-Fi. Settings → Printer finds printers on the network (mDNS `_spinprinter._tcp`,
  then `spinslicer.local`) or takes an address by hand, and the printer's profile fills
  the printer settings. Discovery uses `zeroconf` when it is installed; a typed address
  always works.
- **Plain MP4 too.** A normal MP4 export now carries the print plan in its `comment`
  tag (or `<name>.spin.json` beside it when ffmpeg is missing), which SpinPrinter reads.
- The format is described in `docs/ecosystem.ru.md` of
  [SpinPrinter](https://github.com/v0xeII/SpinPrinter).

### Physics fixes

- **Presharpen:** the gradient used the blur instead of its transpose; with clamped
  edges the top and bottom rows were optimised wrongly. The step size now comes from the
  operator norm.
- **FastCAL L-BFGS:** a line search that found no descent step no longer takes a step
  that raises the objective.
- **Resin absorption hint:** α is the natural-log coefficient, α = 2.303·A per mm = 1/Dp.

### Under the hood

- The headless self-check no longer crashes on Linux CI: the off-screen 3D view uses a
  plain off-screen plotter and ignores Qt paint events.
- New tests: `.spin` round trip and damaged copies, the MP4 tag, upload and printer
  profile against a local server, absolute dose and print time against Beer–Lambert.

## Русский

### `.spin`: один файл на печать

- **Экспорт для принтера.** Печать → «Экспорт .spin» сохраняет видео проекций вместе со
  всем, что нужно принтеру: число оборотов, допуск экспозиции, время печати, направление
  вращения и угол первого кадра, превью детали 320×320 и настройки нарезки. Файл `.spin`
  — обычный ZIP без сжатия, его открывает любой архиватор; sha256 видео ловит битую копию.
- **Отправка на принтер.** Печать → «Отправить на принтер» загружает `.spin` на SpinPrinter
  по Wi-Fi. Настройки → Принтер находит принтеры в сети (mDNS `_spinprinter._tcp`, затем
  `spinslicer.local`) или принимает адрес вручную, а профиль принтера заполняет его
  настройки. Для поиска нужен `zeroconf`, если он установлен; адрес вручную работает всегда.
- **И обычный MP4.** Обычный экспорт MP4 теперь несёт расчёт печати в теге `comment`
  (или в `<имя>.spin.json` рядом, если нет ffmpeg), его читает SpinPrinter.
- Формат описан в `docs/ecosystem.ru.md` репозитория
  [SpinPrinter](https://github.com/v0xeII/SpinPrinter).

### Исправления физики

- **Предрезкость:** градиент брал размытие вместо транспонированного; при прижатых краях
  верхние и нижние строки оптимизировались неверно. Шаг теперь считается по норме оператора.
- **FastCAL L-BFGS:** если линейный поиск не нашёл шаг со спуском, шаг, увеличивающий
  целевую функцию, больше не делается.
- **Подсказка о поглощении смолы:** α — натуральный коэффициент, α = 2,303·A на мм = 1/Dp.

### Внутри

- Самопроверка без экрана больше не падает на Linux CI: 3D-вид без экрана использует
  обычный off-screen plotter и пропускает события отрисовки Qt.
- Новые тесты: `.spin` туда-обратно и битые копии, тег MP4, загрузка и профиль принтера
  на локальном сервере, абсолютная доза и время печати по Бугеру–Ламберту.
