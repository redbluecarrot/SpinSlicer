# SpinSlicer v0.5.4 — New logo / Новый логотип

---

## English

### New look

- **New logo:** the letter S in a spinning resin vial. It replaces the old icon in the
  app window, the taskbar, the Windows installer, the Linux packages and on the
  project page.

### Fixes

- **Cone mode in a bath:** the projector distance now accounts for the flat bath
  window, which makes the air part of the path look longer from inside the liquid.
  Ray divergence in the bath is computed correctly.

### Under the hood

- The Python modules moved into the `spinslicer` package; `SpinSlicer.py` stays as the
  launcher.
- Includes everything from v0.5.3.

---

## Русский

### Новый вид

- **Новый логотип:** буква S во вращающемся флаконе со смолой. Он заменил старую
  иконку в окне программы, на панели задач, в установщике Windows, в пакетах для
  Linux и на странице проекта.

### Исправления

- **Режим конуса в ванне:** расстояние до проектора теперь учитывает плоское окно
  ванны, из-за которого воздушная часть пути изнутри жидкости кажется длиннее.
  Расходимость лучей в ванне считается правильно.

### Внутри

- Модули Python переехали в пакет `spinslicer`; `SpinSlicer.py` остался запускающим
  файлом.
- Включает всё из v0.5.3.
