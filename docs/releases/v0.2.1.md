# SpinSlicer v0.2.1

Packaged desktop builds for Windows and Linux are attached below.

### What's New in v0.2.1

- **Full Bilingual Localization (Русский & English):** Seamless on-the-fly language switching across all menus, tooltips, dialogs, and panels without requiring restart.
- **Enhanced OpenCAL Tomographic Engine:** Accelerated SIRT optimization with C++ multi-threading support and global dose normalization preserving layer-to-layer relative contrast.
- **Physical-Optics Slicing Pipeline:** Ray-tracing support for cylindrical and rectangular vats, custom glass refraction, and immersion index-matching ($n_{glass}, n_{liquid}, n_{resin}$).
- **Modern Dark CAD Interface:** Ergonomic collapsible panels, locked camera rotation, and intuitive model manipulation.
- **Mid-Slice Dose Reconstruction:** Live tomographic verification with $L_2$ error metric calculation.

### Checksums & Verification

All release packages are automatically built, validated via headless self-check, and published by GitHub Actions.
