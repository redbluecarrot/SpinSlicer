# SpinSlicer v0.3.2 — Square Cuvette Coverage / Покрытие углов квадратной кюветы

---

## English

### Overview

SpinSlicer v0.3.2 fixes the projection field in square-cuvette mode. Rotated
corners could fall outside the incident ray field in v0.3.1 and disappear from
some views. The correction keeps sparse matrices, bounded Z batches and native
CPU acceleration.

### What's New in v0.3.2

#### 1. Corrected Square Projection Field

- **Full geometric field:** the square mode uses a constant field equal to the
  outer diagonal, `sqrt(2) × outer side`, at every angle. A 50 mm cuvette therefore
  uses a 70.71 mm field instead of 50 mm. Cylindrical modes keep their original field.
- **Consistent physical scale:** optimization, PNG aspect ratio and preflight
  share the same field. The target voxel grid still spans the original square side.
- **Recorded export geometry:** manifests include detector span and spacing,
  output pixel pitch, voxel-grid span, Z pitch and the actual raster layer count.
  Older frame sets remain readable.

#### 2. Regression Checks and Preserved Acceleration

- **Corner coverage:** tests cover all four finite corner targets at 5-degree
  intervals, with equal refractive indices to isolate geometric clipping.
- **Independent geometry reference:** detector chord lengths are checked against
  slab intersections across multiple square rotations.
- **Actual PNG export:** an offset corner model is checked at 45 degrees for
  visibility, position, physical aspect ratio and manifest consistency.
- **Existing optimizations retained:** float32 CSR storage, detector-bin count,
  voxel-grid resolution, output width and C++/OpenMP acceleration are preserved.
  The complete local test suite passes **108 tests**.

#### 3. Windows & Linux Packages

- **Windows installer:** `SpinSlicer-Setup-0.3.2.exe`.
- **Windows portable:** `SpinSlicer-windows-x64.zip` or standalone `SpinSlicer.exe`.
- **Arch Linux / Manjaro:** `SpinSlicer-0.3.2-1-x86_64.pkg.tar.zst`.
- **Ubuntu / Debian / Mint:** `SpinSlicer-0.3.2-amd64.deb`.
- **Fedora / RHEL:** `SpinSlicer-0.3.2-1.x86_64.rpm`.
- **Linux portable:** `SpinSlicer-linux-x64.tar.gz`.

Regenerate square-mode projections to apply the correction. At the same pixel
count, the wider field increases the physical pixel pitch; it does not preserve
the previous millimetres-per-pixel value. Calibrate the projector to the recorded
field. Software cannot extend a narrower hardware field, and refraction can
independently limit corner coverage. See the [validation report](https://github.com/redbluecarrot/SpinSlicer/blob/v0.3.2/docs/validation/square-detector-field.md).

## Русский

### Обзор

SpinSlicer v0.3.2 исправляет поле проекций в режиме квадратной кюветы. В v0.3.1
повёрнутые углы могли выходить за пределы падающих лучей и пропадать на части
ракурсов. Сохранены разреженные матрицы, обработка Z небольшими блоками и
нативное ускорение на CPU.

### Главные изменения в v0.3.2

#### 1. Исправленное поле квадратной кюветы

- **Полное геометрическое поле:** для всех углов используется постоянная ширина
  по внешней диагонали, `sqrt(2) × внешняя сторона`. Для кюветы 50 мм это 70,71 мм
  вместо 50 мм. В цилиндрических режимах ширина поля прежняя.
- **Согласованный физический масштаб:** оптимизатор, пропорции PNG и проверка
  перед расчётом используют одно поле. Воксельная сетка сохраняет исходную сторону квадрата.
- **Геометрия в метаданных:** сохраняются ширина поля, шаг детектора и пикселя
  кадра, размер воксельной сетки, шаг Z и фактическое число слоёв растеризации.
  Старые наборы кадров по-прежнему читаются.

#### 2. Проверки углов и сохранённое ускорение

- **Покрытие углов:** тестируются конечные участки во всех четырёх углах с шагом
  ракурса 5°. Равные показатели преломления позволяют отдельно проверить отсечение поля.
- **Независимая проверка геометрии:** длины хорд сверяются с аналитическим
  пересечением луча с границами квадрата при разных поворотах.
- **Проверка сохранённых PNG:** для смещённой к углу модели проверяются видимость
  при 45°, положение в кадре, физические пропорции и согласованность метаданных.
- **Оптимизации сохранены:** float32, CSR, число лучей детектора, разрешение
  воксельной сетки, ширина кадров и C++/OpenMP. Полный локальный набор — **108
  пройденных тестов**.

#### 3. Пакеты для Windows и Linux

- **Windows, установщик:** `SpinSlicer-Setup-0.3.2.exe`.
- **Windows, портативная версия:** `SpinSlicer-windows-x64.zip` или `SpinSlicer.exe`.
- **Arch Linux / Manjaro:** `SpinSlicer-0.3.2-1-x86_64.pkg.tar.zst`.
- **Ubuntu / Debian / Mint:** `SpinSlicer-0.3.2-amd64.deb`.
- **Fedora / RHEL:** `SpinSlicer-0.3.2-1.x86_64.rpm`.
- **Linux, портативная версия:** `SpinSlicer-linux-x64.tar.gz`.

Проекции квадратного режима нужно сгенерировать заново. При прежнем числе
пикселей расширенное поле увеличивает физический шаг пикселя — прежнее значение
мм/пиксель не сохраняется. Проектор нужно откалибровать на указанную ширину поля.
Программа не расширяет физическое поле оборудования; преломление также может
отдельно ограничивать покрытие углов. Подробности — в [отчёте проверки](https://github.com/redbluecarrot/SpinSlicer/blob/v0.3.2/docs/validation/square-detector-field.md).
