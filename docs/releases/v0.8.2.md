# SpinSlicer v0.8.2 — Updates from inside the slicer, OpenCAL resin by default / Обновления из слайсера, смола OpenCAL по умолчанию

---

## English

### Updates

- **Settings → Interface → Updates.** Shows the installed version and checks GitHub for a newer
  release. When one is found, "install" downloads it with progress and restarts into it.
- **Checks at startup** at most once a day; the switch "Check at startup" turns it off. A failed
  check (no internet) stays quiet. A found version also shows in the status bar.
- **Each copy updates its own way.** Installed with Setup: the new Setup runs silently and starts
  the new version. A single `SpinSlicer.exe` or the binary from the Linux archive: the new file
  takes the old one's place. `.deb` / `.rpm` packages and source checkouts: the release page opens.
- **Verified.** Every download is checked against the SHA-256 GitHub publishes for the file; a
  mismatch is never installed. The update waits while a calculation or a print is running.
- This is the first version with the updater: from 0.8.1 update by hand once more, the next
  versions arrive from inside the slicer.

### Resin

- **OpenCAL Resin Clear by default** (UDMA, camphorquinone 2.5 mM / EDAB 5 mM / MDEA 200 mM,
  cured with blue 450 nm light). Absorption 0.020 /mm is estimated from camphorquinone at
  450 nm; refraction 1.48 is UDMA's. The gel dose is not published: find it with the dose scale.
  A measured absorption is better: enter it in Settings → Resin.
- Earlier placeholders (absorption 0, refraction 1.50) give way to these values once; values set
  by hand stay.

### Interface

- **Light step:** the result is shown first, the game below it.
- **Taskbar icon on Windows.** The installer's shortcuts now carry the app's taskbar identity, so
  the icon no longer goes blank after a while. If a pinned icon is already blank, unpin it and pin
  it again once.

## Русский

### Обновления

- **Настройки → Интерфейс → Обновления.** Показывает установленную версию и проверяет на GitHub,
  есть ли новее. Если есть, «установить» скачивает её с прогрессом и перезапускает слайсер.
- **Проверка при запуске** — не чаще раза в сутки; переключатель «Проверять при запуске» её
  выключает. Неудачная проверка (нет интернета) ничего не показывает. Найденная версия видна ещё и
  в строке состояния.
- **Каждая копия обновляется по-своему.** Установлена через Setup — новый Setup запускается тихо и
  открывает новую версию. Один `SpinSlicer.exe` или бинарник из Linux-архива — новый файл встаёт
  на место старого. Пакеты `.deb` / `.rpm` и запуск из исходников — открывается страница релиза.
- **С проверкой.** Каждый скачанный файл сверяется с SHA-256, который публикует GitHub; при
  несовпадении он не устанавливается. Пока идёт расчёт или печать, обновление ждёт.
- Это первая версия с обновлением: с 0.8.1 обновитесь вручную ещё один раз, дальше новые версии
  придут прямо из слайсера.

### Смола

- **OpenCAL Resin Clear по умолчанию** (UDMA, камфорхинон 2,5 мМ / EDAB 5 мМ / MDEA 200 мМ,
  отверждается синим светом 450 нм). Поглощение 0,020 /мм — оценка по камфорхинону на 450 нм;
  преломление 1,48 — у UDMA. Доза геля не опубликована: её находит шкала дозы. Измеренное
  поглощение точнее — впишите его в Настройки → Смола.
- Прежние заглушки (поглощение 0, преломление 1,50) один раз заменяются этими значениями;
  введённые вручную остаются.

### Интерфейс

- **Шаг «Свет»:** сначала результат, под ним игра.
- **Иконка на панели задач Windows.** Ярлыки установщика теперь несут идентификатор приложения,
  и иконка больше не пропадает со временем. Если закреплённая иконка уже пустая — открепите и
  закрепите её заново один раз.
