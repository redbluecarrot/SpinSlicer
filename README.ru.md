SpinSlicer — локальный исследовательский прототип для томографической объёмной
аддитивной печати (VAM). Он объединяет настольный интерфейс на PyQt6, 3D-вьюпорт
на PyVista/VTK, генератор проекций и проигрыватель кадров.

Приложение готовит проекции и показывает предпросмотр сгенерированных кадров.
Оно не управляет реальным проектором, ванной со смолой или поворотным столиком.

## Возможности

Стабильная версия v0.3.2 включает **Slicer (3D)**, **Projector (Video)** и боковую панель **Settings**.
См. [заметки о выпуске](docs/releases/v0.3.2.md).

- **Разреженная оптика с ограниченной памятью:** полноразмерные CSR-матрицы лучей и пакетная по Z оптимизация сохраняют сетку 256×256 и 360 углов. Условия измерений и потребление ресурсов приведены в [отчёте о численной валидации](docs/validation/physical-optics-v0.3.1.md).
- **Нативный параллельный SIRT на OpenMP:** многопоточный C++-бэкенд (`sirtsolver.dll` / `sirtsolver.so`) работает на любых обычных CPU без дорогих дискретных GPU.
- **Удобное CAD-рабочее пространство:** широкий интерактивный 3D-вьюпорт слева и быстрые параметры справа.
- **Чистый 3D-вьюпорт:** орбита трекбола, панорамирование и масштаб без лишних элементов.
- **Загрузка и трансформация STL-моделей** в физических миллиметрах.
- **Конвейер физической оптики:** трассировка лучей для цилиндрических и прямоугольных ванн с согласованием показателей преломления ($n_{glass}, n_{liquid}, n_{resin}$).
- **Сохранение внутренних отверстий и резьбы** в загруженных STL-моделях по умолчанию.
- **Предпросмотр кадров** в виде вращающегося видео и экспорт в MP4.
- **Двуязычный интерфейс:** мгновенное переключение между русским и английским.

## Установка и пакеты

### Готовые пакеты (GitHub Releases)

Скачайте готовые сборки со страницы [Releases](https://github.com/redbluecarrot/SpinSlicer/releases):

- **Windows 10 / 11:**
  - **Установщик:** скачайте и запустите `SpinSlicer-Setup-0.3.2.exe`
  - **Портативная версия:** скачайте `SpinSlicer-windows-x64.zip`, распакуйте и запустите `SpinSlicer.exe`
- **Arch Linux / Manjaro:**
  ```bash
  sudo pacman -U SpinSlicer-0.3.2-1-x86_64.pkg.tar.zst
  ```
- **Ubuntu / Debian / Mint:**
  ```bash
  sudo apt install ./SpinSlicer-0.3.2-amd64.deb
  ```
- **Fedora / RHEL / openSUSE:**
  ```bash
  sudo dnf install ./SpinSlicer-0.3.2-1.x86_64.rpm
  ```
- **Портативная сборка для Linux:**
  ```bash
  tar -xzf SpinSlicer-linux-x64.tar.gz
  ./SpinSlicer
  ```

### Запуск из исходников

SpinSlicer поддерживает Python 3.11 и 3.12.

```bash
python -m venv .venv
# Windows
.venv\Scripts\activate
# macOS/Linux
# source .venv/bin/activate

python -m pip install -r requirements.txt -r requirements-dev.txt
python build_sirt.py
```

Запуск приложения:

```bash
python SpinSlicer.py
```

## STL-модели с резьбой

Загрузите гайку как обычный STL через **Load STL**. Внутренние отверстия и
резьба по умолчанию сохраняются при растеризации сечений, в том числе при
включённой опции восстановления сетки. Шаг и глубина резьбы должны занимать
несколько вокселей при выбранном разрешении сетки: слишком мелкие элементы
невозможно надёжно представить в любом воксельном проекторе.

## Бэкенды проекций

Модуль проекций следует тем же концептуальным этапам, что Tomo и VAMToolbox:

1. вокселизация целевой геометрии;
2. генерация или оптимизация последовательности проекций по равномерно распределённым углам;
3. применение общего масштаба проекций и экспорт последовательности кадров для воспроизведения.

Бэкенд по умолчанию трассирует лучи с преломлением по Снеллиусу через пробирку
или кювету, интегрирует пересечения вокселей и затухание по Бугеру–Ламберту–Беру,
затем подбирает неотрицательные проекции относительной дозы методом SIRT.
Необязательная нативная библиотека ускоряет тот же расчёт на C++/OpenMP.
Python API также сохраняет внутренний путь Радона и необязательную совместимость с VAMToolbox.

Предпросмотр восстанавливает значения серого из экспортированных PNG и сообщает
RMSE формы относительной дозы после подгонки общего масштаба. Это не
калиброванный прогноз отверждения. Отражение Френеля, рассеяние, отклик
материала и абсолютная доза оборудования требуют дополнительной калибровки.
См. [модель и воспроизводимые проверки](docs/validation/physical-optics-v0.3.1.md).

Квадратные кюветы используют фиксированное поле проекции, равное внешней
диагонали, при каждом угле. Это значение и физический шаг пикселя записываются в
манифест; калибровка проектора должна использовать именно его. См. [коррекцию
квадратного поля и проверки покрытия углов](docs/validation/square-detector-field.md).

## Формат вывода

Каждая завершённая генерация создаёт уникальный каталог запуска:

```text
output_frames/
└── run-20260903T120000Z-a1b2c3d4/
    ├── frame_0000.png
    ├── frame_0001.png
    ├── slice_meta.json
    ├── dose_stats.txt
    ├── reconstruction_dose.npy
    ├── reconstruction_target.npy
    ├── reconstruction_preview.png
    └── manifest.json
```

`manifest.json` хранит идентификатор источника (если источник — STL), тип и
параметры модели, матрицу трансформации, бэкенд проекций, настройки смолы,
размеры кадров и `complete: true`. Репозиторий кадров проверяет число
изображений, размеры, метаданные, лимиты по байтам и статус завершения, прежде
чем проигрыватель сможет использовать запуск. Старые плоские папки с
`frame_*.png` остаются читаемыми.

| Файл | Назначение |
| --- | --- |
| `SpinSlicer.py` | Главное окно, выбор языка, общая строка состояния и журнал. |
| `assets/spinslicer.svg` | Иконка приложения для интерфейса и пакетов. |

| `nut_dialog.py` | Устаревший диалог резьбовой гайки (для совместимости API). |

| `ui_panels.py` | Настройки принтера/процесса и компактные элементы трансформации модели. |
| `slicing_engine.py` | Растеризация сечений, планирование проекций и проверенный экспорт PNG. |
| `optics/` | Лучи Снеллиуса, точные интегралы по путям в вокселях и неотрицательный SIRT относительной дозы. |
| `vam_backend.py` | Необязательный адаптер VAMToolbox CAL и нормализация раскладки синограммы. |
| `video_tab.py` | Воспроизведение кадров и экспорт в MP4. |
| `frame_io.py` | Проверяемое хранение наборов кадров, метаданные и манифесты. |
| `profiles.py` | Проверенные настройки станка и смолы, записываемые с каждым запуском. |
| `validation.py` | Предварительная проверка сетки/ресурсов и бюджеты нагрузки. |
| `model_node.py` | Исходная сетка и состояние трансформации, удобное для GPU. |
| `viewport.py` | 3D-вьюпорт на PyVista/VTK. |
| `workers.py` | Фоновые Qt-воркеры для загрузки модели, генерации и видео. |
| `synthetic_shapes.py` | Канонические фантомы для численной валидации. |
| `tests/` | Тесты геометрии, проекций, хранения, безопасности и валидации. |

## Валидация и безопасность

Перед генерацией SpinSlicer проверяет конечность значений сетки, число
треугольников, границы, помещаемость в ванну, число слоёв, оценку памяти,
размеры кадров и бюджеты вывода. Длительные задачи выполняются в воркерах
`QThread` и поддерживают отмену. Каталоги вывода фиксируются только после
успешной проверки всех PNG-файлов и метаданных. Локальные пути открываются
через настольный API Qt, а не через команду оболочки.

## Выпуски

Чтобы опубликовать готовые сборки, обновите версию в `pyproject.toml`, затем
создайте и отправьте соответствующий тег версии:

```bash
git tag vX.Y.Z
git push origin vX.Y.Z
```

Workflow `Build release artifacts` публикует файлы на [странице GitHub
Releases](https://github.com/redbluecarrot/SpinSlicer/releases):

- `SpinSlicer-windows-x64.zip` — содержит `SpinSlicer.exe` для 64-битной Windows;
- `SpinSlicer-Setup-<version>.exe` — установщик Windows для пользователя с ярлыками в меню «Пуск» и, по желанию, на рабочем столе;
- `SpinSlicer.exe` — автономный исполняемый файл Windows;
- `SpinSlicer-linux-x64.tar.gz` — портативный 64-битный исполняемый файл Linux;
- `SpinSlicer-<version>-amd64.deb` — пакет Debian/Ubuntu;
- `SpinSlicer-<version>-1.x86_64.rpm` — пакет, совместимый с Fedora/RHEL.

В Linux распакуйте архив и выполните `chmod +x SpinSlicer && ./SpinSlicer`.
Либо установите нативный пакет: `sudo apt install ./SpinSlicer-<version>-amd64.deb`
или `sudo dnf install ./SpinSlicer-<version>-1.x86_64.rpm`. Оба пакета добавляют
`SpinSlicer` в меню приложений. Сборки для Linux рассчитаны на x86_64.

по обратной связи от рассеянного света в реальном времени. SpinSlicer пока
реализует только генерацию проекций и предпросмотр кадров; аппаратная обратная
связь для автоэкспозиции выходит за рамки этого настольного прототипа.
